NMAP

1. Scan a network and find out which servers and devices are up and running

in the target field, enter your IP. ex: ip = 192.168.0.100, then target field = 192.168.0.0/24 or 192.168.1.2 then target field = 192.168.1.0/24

2. Scan multiple IP Address

enter 3 IP Addresses in the target field

3. Scan by excluding a host

in the command line enter: nmap 192.168.1.0/24 --exclude 192.168.1.101

4. Fast nmap scanning for a network range

nmap -F 192.168.1.10/24

5. To see packets sent and received using nmap

nmap --packet-trace [IP_ADDRESS]
