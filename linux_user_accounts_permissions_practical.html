Linux User Accounts and Permissions

Practical: Creating user accounts, passwords, groups, protected directories, and restricted sudo permissions.

Aim

To protect a personal computer system by creating user accounts with passwords and different types of user permissions for safety and security.

1. Create Two Groups

sudo groupadd dev1
sudo groupadd dev2

2. Create Users

These commands create the users and prompt you to set their passwords and enter optional account details.

sudo adduser dev1_user
sudo adduser dev2_user

3. Add Each User to Its Group

sudo usermod -aG dev1 dev1_user
sudo usermod -aG dev2 dev2_user

4. Create Protected Directories

Create one directory for each development group, assign the group ownership, and allow access to the owner and group only.

sudo mkdir /opt/dev1_files
sudo mkdir /opt/dev2_files

sudo chown :dev1 /opt/dev1_files
sudo chown :dev2 /opt/dev2_files

sudo chmod 770 /opt/dev1_files
sudo chmod 770 /opt/dev2_files

5. Configure Group-Based sudo Permissions

Open the sudoers configuration safely with visudo:

sudo visudo

Add these rules to the file:

%dev1 ALL=(ALL) /usr/bin/apt, /usr/bin/apt-get
%dev2 ALL=(ALL) /usr/bin/journalctl, /usr/bin/systemctl status *
Important: Use visudo rather than editing /etc/sudoers directly. It checks the file for syntax errors before saving. These rules grant the listed command permissions to members of the corresponding groups.

6. Test Allowed and Denied Commands

Test as dev1_user:

su - dev1_user
sudo apt update
ls /opt/dev2_files
exit

Test as dev2_user:

su - dev2_user
sudo journalctl
ls /opt/dev1_files
exit
Expected result: Each user should be able to access their own group directory, but should be denied access to the other group's directory. The sudo tests should also reflect the commands permitted by the sudoers rules. A denied directory listing may show “Permission denied.”
Note: The original test command contained su – dev2_use. It has been corrected to su - dev2_user to match the account created in Step 2. Use a normal hyphen (-) in terminal commands.
