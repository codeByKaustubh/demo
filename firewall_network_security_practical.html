Firewall Network Security Practical

Demonstrating firewall features and configuring firewall security using UFW on Ubuntu.

Aim

To demonstrate the features of a firewall in providing network security and to configure firewall security.

Python Server Code

Create a file named test.py and add the following Python code. This starts a simple HTTP server on port 8080 and logs incoming connections.

import socket

s = socket.socket()
s.bind(("0.0.0.0", 8080))
s.listen()

while 1:
    c, a = s.accept()
    print("Hit from", a)
    c.recv(1024)
    c.send(b"HTTP/1.1 200 OK\r\nContent-Type: text/plain\r\n\r\nHello! Hit Logged.")
    c.close()

1. Reset UFW Firewall Rules

Reset UFW to its default configuration. This removes existing UFW rules and may prompt for confirmation.

sudo ufw reset

2. Set Default Firewall Policies

Deny incoming connections by default and allow outgoing connections.

sudo ufw default deny incoming
sudo ufw default allow outgoing

3. Enable the Firewall

sudo ufw enable
sudo ufw reload

4. Run the Python Server

In the Ubuntu terminal, run:

python3 test.py

5. Test from the Host Browser

Find the Ubuntu system's IP address, then enter the following address in the host computer's browser:

http://<ubuntu_ip>:8080

With incoming traffic denied by the firewall, the browser connection should be blocked or time out. The server should not log a successful connection.

6. Allow a Specific Host IP Address

Replace <host_ip> with the IP address of the host computer. This rule allows that host to connect to TCP port 8080 on Ubuntu.

sudo ufw allow from <host_ip> to any port 8080 proto tcp
sudo ufw reload
sudo ufw status numbered

7. Run the Python Server Again

If the server is not already running, start it in the Ubuntu terminal:

python3 test.py

8. Test Again from the Host Browser

Open the same address in the host computer's browser:

http://<ubuntu_ip>:8080

The permitted host should now receive the response:

Hello! Hit Logged.

The Ubuntu terminal should display the connecting host's IP address.

Important notes
  • Use the Ubuntu machine's IP address for <ubuntu_ip> and the host computer's IP address for <host_ip>.
  • Keep the Python server running while testing from the browser.
  • If Ubuntu is running in a virtual machine, its network mode and routing must allow the host to reach it. In NAT mode, additional port forwarding may be required; bridged networking or a suitable host-only network may also be used.
  • This practical configures UFW on Ubuntu. Windows Firewall is a separate firewall and is not configured by these commands.
Practical outcome: The firewall initially blocks unsolicited incoming connections. After adding a rule for a specific source IP address and TCP port 8080, that host is allowed to reach the Python server.
