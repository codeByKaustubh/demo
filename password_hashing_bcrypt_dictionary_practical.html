Password Hashing and Dictionary Attack

Demonstrating bcrypt password hashing and checking a small list of common passwords.

Aim

To demonstrate password hashing using bcrypt and a simple dictionary attack for password verification.

Python Code: pass.py

Create a file named pass.py and enter the following program. It securely prompts for a password, hashes it using bcrypt with a randomly generated salt, and checks each word in a small sample dictionary against the hash.

import bcrypt
import getpass

password = getpass.getpass("Enter password: ")

hashed = bcrypt.hashpw(
    password.encode(),
    bcrypt.gensalt()
)

print("\\nHash:", hashed.decode())

print("\\nTrying dictionary...")

words = ["123456", "password", "admin123", "qwerty",
         "letmein", "welcome", "Password123", "student123"]

for word in words:
    print("Trying:", word)
    if bcrypt.checkpw(word.encode(), hashed):
        print("\\nPassword found:", word)
        break
else:
    print("\\nPassword not found.")

1. Create the Python File

Open the Ubuntu terminal and create the file:

nano pass.py

Paste the Python code above. Save using Ctrl + O, press Enter, and exit using Ctrl + X.

2. Install the bcrypt Library

If bcrypt is not already installed, install it with:

python3 -m pip install bcrypt

If your Ubuntu system blocks system-wide pip installation, use a virtual environment:

python3 -m venv venv
source venv/bin/activate
python -m pip install bcrypt

3. Run the Program

python3 pass.py

Enter a test password when prompted. The password input is hidden while typing because the program uses getpass.

4. Observe the Dictionary Check

The program generates and displays a bcrypt hash, then checks the entered password against each word in this list:

123456
password
admin123
qwerty
letmein
welcome
Password123
student123

If the entered password matches one of these words, the program displays Password found and the matching word. Otherwise, it displays Password not found.

Important notes
  • This is a controlled demonstration. Use a test password, not your real account password.
  • Bcrypt is a password-hashing algorithm, not encryption. It is designed to make password guessing computationally expensive.
  • Bcrypt generates a random salt, so hashing the same password again usually produces a different hash. bcrypt.checkpw() verifies a candidate password against the stored hash correctly.
  • This program hashes the password entered during the current run and checks the sample dictionary against it. It is not testing a real account or an existing password database.
  • The dictionary contains only eight sample words. “Password not found” means only that none of those words matched; it does not prove the password is immune to guessing.
Practical outcome: The program demonstrates how bcrypt stores a salted password hash and how candidate passwords can be verified against that hash using a small dictionary.
