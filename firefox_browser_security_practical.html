Firefox Browser Security Practical

Configuring Mozilla Firefox security policies on Ubuntu using a JSON policy file.

Aim

To implement security measures for a web browser (Mozilla Firefox or Google Chrome) by configuring browser policies. This practical uses Mozilla Firefox.

Python Code

Create a file named test.py and paste the following program. It creates a Firefox policy directory and writes the security settings to policies.json.

import json
import os

POLICIES = {
    "policies": {
        "DisableTelemetry": True,
        "DisablePocket": True,
        "DisableFirefoxStudies": True,
        "EnableTrackingProtection": {
            "Value": True,
            "Cryptomining": True,
            "Fingerprinting": True
        },
        "HTTPSOnlyMode": "enabled",
        "PasswordManagerEnabled": False,
        "OfferToSaveLogins": False,
        "Permissions": {
            "Camera": {"BlockNewRequests": True},
            "Microphone": {"BlockNewRequests": True},
            "Location": {"BlockNewRequests": True}
        },
        "Preferences": {
            "security.tls.version.min": 3,
            "privacy.donottrackheader.enabled": True,
            "browser.safebrowsing.phishing.enabled": True,
            "browser.safebrowsing.malware.enabled": True
        }
    }
}

path = "/etc/firefox/policies"
os.makedirs(path, exist_ok=True)

with open(f"{path}/policies.json", "w") as f:
    json.dump(POLICIES, f, indent=4)

print("Firefox security policies applied successfully.")

1. Open Firefox and Check Existing Policies

Open Firefox from the Ubuntu terminal:

snap run firefox

In Firefox, type the following into the browser's address bar and press Enter:

about:policies

Open the Active tab to see which enterprise policies are currently applied.

2. Create the Python File

In a terminal, create or open the Python file:

nano test.py

Paste the Python code above, save with Ctrl + O, press Enter, and exit with Ctrl + X.

3. Run the Python Program with Administrator Privileges

The program writes to /etc, which normally requires administrator privileges. Run:

sudo python3 test.py

You should see:

Firefox security policies applied successfully.

4. Restart Firefox and Verify the Policies

Close all Firefox windows completely, then launch Firefox again:

snap run firefox

In the Firefox address bar, open:

about:policies

Check the Active tab for the configured policies. Check the Errors tab if any policy is not accepted.

Important notes
  • about:policies is entered in Firefox's address bar, not in the Ubuntu terminal.
  • Use sudo python3 test.py because the script writes to the system directory /etc/firefox/policies.
  • This practical configures Firefox, not Google Chrome.
  • If the policies do not appear in Firefox, verify that your Firefox installation recognizes /etc/firefox/policies/policies.json. Policy-file discovery can vary with packaging, including Snap installations.
  • Some settings can be version-dependent. The Firefox Errors tab helps identify invalid or unsupported policy entries.
Practical outcome: Firefox is configured with policies intended to strengthen privacy and security, including tracking protection, HTTPS-only mode, blocked new camera/microphone/location requests, and disabled browser password saving.
